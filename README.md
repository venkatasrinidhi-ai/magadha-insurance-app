# 🛡️ Magadha Life & Health Insurance App

A mobile-styled interactive insurance portal built using **Python** and **Flet**. The application supports user authentication, automated SQLite persistence, interactive 3D virtual card flip, and comprehensive claim processing.

---

## ✨ Key Features

- **Dynamic Startup Animation**: Smooth brand logo zoom animation leading into the login screen.
- **Secure Authentication**: Mobile number login, app permissions consent dialog, and auto-focus 4-digit OTP verification with animated tick feedback.
- **Customer Identity Verification**: Post-OTP form to verify linked mobile, policy number, and Aadhaar.
- **Interactive Virtual Card (3D Right-Flip)**:
  - **Life Insurance Side**: Covers natural death, accidental death, critical illness payouts, and nominee security.
  - **Health Insurance Side**: Platinum cashless pass covering 4 family members across 14,000+ network hospitals.
- **Home Dashboard**:
  - Masked claim amount with eye toggle visibility.
  - 14-month continuous premium payment history tracking.
- **Incident Claims**: Dual-action direct claims for Life and Health with real-time status tracking.

---

## 🛠️ Tech Stack

- **Frontend / Framework**: [Flet](https://flet.dev/) (Flutter for Python)
- **Database**: SQLite3 (Auto-migration schema)
- **Language**: Python 3.10+
